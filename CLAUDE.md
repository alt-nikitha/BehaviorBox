# CLAUDE.md

This is BehaviorBox2.0 where we discover fine-grained features of pre-training data that share both training trajectory patterns and semantic similarity. We plan to find which features track the performance of downstream tasks such as gsm8k, arc_challenge, blimp, etc by measuring the similarity of the normalised performance curves with the median probability curves of the pre-training samples that represent a feature.

For more details about extraction of features, see README.md
